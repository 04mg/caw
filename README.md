## Build

### Prerequisites
- [Go](https://go.dev/dl/) 1.21+
- [Node.js](https://nodejs.org/) 20+
- npm
- [Make](https://www.gnu.org/software/make/)

### Build
```sh
make build
```

### Lint
```sh
make lint
```
