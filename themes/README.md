# Themes

Ready-made Caw customization presets. **Caw Dark** and **Caw Light** are bundled; the presets below load from GitHub in Appearance settings.

## Available themes

| Theme | File | Description |
| --- | --- | --- |
| **One Dark Pro** | [`presets/one-dark-pro.json`](presets/one-dark-pro.json) | Atom's iconic One Dark with a soft slate-grey background |
| **Dracula** | [`presets/dracula.json`](presets/dracula.json) | Deep purple-tinted background with vivid candy colors |
| **Monokai Pro** | [`presets/monokai-pro.json`](presets/monokai-pro.json) | Modern successor of the original Monokai scheme |
| **Tokyo Night** | [`presets/tokyo-night.json`](presets/tokyo-night.json) | Calm, neon-inspired night palette |

## How to apply

1. Open **Settings** > **Appearance**.
2. Select a theme from the **Theme** dropdown, or **Custom** to edit the persisted JSON directly.
3. The theme applies immediately and persists for every connected device.
